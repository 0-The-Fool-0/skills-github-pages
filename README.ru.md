# GitHub Pages — завершённое упражнение

[English version](README.md)

Этот репозиторий содержит материалы GitHub Skills для знакомства с **GitHub Pages** и публикацией статического сайта из репозитория.

## Что отрабатывается

- настройка конфигурации статического сайта;
- публикация контента из GitHub-репозитория;
- базовая работа с Markdown-страницами и записями;
- использование workflow и шагов учебного задания.

В корне находятся `index.md`, `_config.yml` и каталог `_posts/`; папка `.github/steps/` содержит инструкции, а `.github/workflows/` автоматизирует этапы упражнения. Эти файлы нужны для учебного сценария и не относятся к сборочному мусору.

## Как использовать

1. Прочитайте исходный [README на английском](README.md).
2. Следуйте шагам из `.github/steps/`.
3. Проверьте настройки GitHub Pages в параметрах репозитория.
4. Сохраняйте учебные workflow, если хотите повторно проходить автоматизированное упражнение.

Это учебный проект для знакомства с GitHub Pages, а не самостоятельный веб-фреймворк.
